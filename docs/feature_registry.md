# Local Feature Registry

Record downstream-local features here when they may overlap with future template releases.

These entries are local to each independent factory. The update script preserves this file and uses it to detect semantic overlap.

Example:

```text
## local-ui-theme-controls

- title: Product-specific UI color controls
- tags: ui-theme, color, branding, interface-customization
- files: products\my-product\source\public\index.html
```
