# score-control 模块

## 当前策略

- `targets` 是最低门槛。
- `quality_goal` 是尽量追求的目标。
- 默认 `quality_goal.total = 9`。
- 达到最低门槛后，如果还有轮次，会继续寻找更高分候选。
- 新候选更高分时，可以替换已选候选池里的低分候选。

## 适用产品

所有需要“不是刚好达标，而是尽量高分”的广告文案工具。


## 动态重试提示

重试不应只是重复同一个 prompt 抽卡。每一轮应读取上一轮被拒候选和已选候选的确定性评分结果，聚合主要失败原因，并在下一轮 prompt 中只加入有限数量的针对性改写建议。

推荐诊断维度：

- `over`：超出字节限制，下一轮优先压缩结构。
- `compliance`：命中合规禁区，下一轮移除 unsupported claims。
- `hook`：开头吸引力不足，下一轮要求首三分之一出现 hook word、数字或问题。
- `rel`：利益点词不足，下一轮要求使用选定 benefit 的具体动作词。
- `cta`：行动动词不足，下一轮要求自然 CTA。
- `space`：空间利用不足，下一轮要求接近但不超过字节上限。
- `total`：总分未达 quality_goal，下一轮组合提升 hook、benefit keyword 和 CTA，而不是只换同义词。

每轮最多聚焦前三个失败维度，返回 `retry_history` 便于验收。不得无限堆提示词，也不得覆盖产品自身的地区、语言、合规和卖点限定。
